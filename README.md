# Jal Sanchaee Navachar V2

A technology-driven smart-irrigation planning and community water-conservation platform for farmers and communities.

## MVP principles

- Online-first planning with clear coordinator review before a community plan is finalized.
- Community water credits are non-transferable.
- If weather data is unavailable, pause planning rather than inventing a forecast or silently using stale data.
- Roles are planned as `farmer`, `community_coordinator`, and `platform_admin`.

## Current implementation

The repository currently contains only the project README. This first implementation adds a backend health endpoint and validated server configuration; it does **not** implement persistence, authentication, irrigation allocation, weather integration, coordinator workflows, or water credits.
